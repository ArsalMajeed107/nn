# AI Internship Matcher — Frontend

A responsive HTML, CSS and JavaScript starter website for organizing AI/ML internship opportunities.

## Run in VS Code
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and select **Open with Live Server**.

No npm install or build process is required.

## Features
- Responsive dashboard layout
- Search by role, organization and skills
- Filter by location, application status and field
- Save / unsave opportunities
- Add opportunities through a form
- Browser localStorage persistence
- Light / dark theme toggle

## Important project limitation
This is a front-end starter, not a live internship search engine. The three initial cards are illustrative demo records and are marked **Unverified**. The website does not scrape websites, verify current openings, or submit applications. To meet the full project proposal, connect a backend/API that checks official organization pages and stores evidence, verification timestamps, eligibility, deadlines and official application URLs. Never present demo data as real vacancies.

## Files
- `index.html` — page structure
- `style.css` — layout and responsive styling
- `script.js` — filters, saved items, form and local storage
